# Blackjack - Duelo contra el computador

Mini proyecto 1 de FPOE (750014C) - Grupo 22.
Juego de 21 Blackjack hecho en Java y JavaFX, con patrón MVC.

## Tecnologías
- Java 27
- JavaFX 25
- Maven
- JUnit 5

## Cómo ejecutar
Ejecutar la clase `blackjack_grupo22.Launcher` desde IntelliJ IDEA,
o desde la terminal: `mvn javafx:run`
